# AGENTS.md

Rules for automated assistants working in this repository.

## Public vs local

- Keep **public** files free of secrets, personal contact details, localhost/IPs/ports, and private design drafts.
- Project-private notes and detailed design live under **`.local/`** (gitignored). If that folder exists, read it before non-trivial work.

## Stack (summary)

Browser game: HTML, Canvas 2D, vanilla JavaScript. esbuild is a development-only production build tool; no runtime dependencies.

## Do

- Prefer small, verifiable changes
- Ask before adding dependencies or destructive git operations
- Use human-only commit messages (no AI co-author / “generated by” trailers)
- Keep README and other public docs generic (how to serve statically is enough; no machine-specific URLs)

## Do not

- Commit `.env` values, keys, or credentials
- Force-push or amend published history unless asked
- Delete project data or run destructive system actions without explicit approval
- Publish internal specs or private agent notes from `.local/`
